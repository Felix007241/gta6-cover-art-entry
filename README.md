Vice City Cover Maker: an offline web app that turns any photo and caption into multi-panel GTA 6-style cover art, in a Vice City sunset / neon grade, exported as PNG in 1080×1080, 1080×1350 and 1920×1080 post sizes. Photos never leave the machine. No Rockstar Games logo, official artwork or fonts.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080, load up to 3 photos, add a caption and subtitle, pick a style and size, and Export PNG. Or open `app/index.html` directly in desktop Chrome — it works offline from its own static files.
